# JavaScript DOM and Event Handling

## Description
This is a simple JavaScript project that demonstrates DOM manipulation and event handling. Users can enter their name to display a greeting message and click on different color boxes to change their background color.

## Features
- Display a greeting message using the user's name.
- Change box background colors on click.
- Handle button clicks using JavaScript events.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Open the project in VS Code.
2. Run the "index.html" file in your browser.
3. Enter your name in the input field.
4. Click the **Greet** button to display your greeting.
5. Click any color box to change its background color.

## Project Structure
- "index.html" – Contains the HTML structure.
- "style.css" – Contains the styling.
- "script.js" – Handles DOM manipulation and events.
